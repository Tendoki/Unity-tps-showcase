# Unity TPS — примеры кода

Учебный проект на Unity: управление персонажем от третьего лица, противники с состояниями и сохранение прогресса через Firebase или собственный REST API.

Что сделано:

- [Персонаж и движение](Assets/Game/Scripts/Player/ThirdPerson) — управление, движение и камера.
- [Противники](Assets/Game/Scripts/Enemies) — обнаружение цели, перемещение и состояния поведения.
- [Запуск игры](Assets/Game/Scripts/Infrastructure/Game.cs) — регистрация сервисов и переходы между состояниями загрузки.
- [Сохранение и авторизация](Assets/Game/Scripts/Services) — работа с Firebase и REST API.
- [REST-бэкенд](Backend/Backend) — небольшой сервер на ASP.NET Core с SQLite.

Из проекта здесь опубликованы только C#-исходники. Сцены, ассеты, сторонние библиотеки и конфигурация Firebase не включены, поэтому этот репозиторий предназначен для просмотра кода, а не для запуска проекта в Unity.
